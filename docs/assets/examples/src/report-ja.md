# AIプロダクトマネージャー求職レポート

調査日：2026年9月11日｜中国本土、北京を優先｜希望条件：固定の税引前月給が30,000元超

## 1. どこから始めるか

まず北京のAI評価とAIアプリケーションの求人を調べることをおすすめします。あなたはユーザーの課題分析、AIワークフロー、一括評価、個人プロダクトの開発を経験しており、これらの求人の仕事内容と重なります。今の履歴書では、あなた自身が担当した機能、エンジニアとの協力の仕方、リリース後の利用状況がまだ伝わりません。

どの求人も固定月給を公開していません。準備に時間をかける前に、希望額に届くかを確認してください。

今回の一覧は公式採用ページの60件、48グループの求人です。このうち16グループは募集要項の全文があり、32グループは一覧の概要だけです。

| 連絡する順番 | 求人と確認する点 |
|---|---|
| まず北京の求人 | Aime特化型アプリ、社内情報システムのAI評価、オフィス向けAIの効果評価。ワークフローと評価の経験が関係します。担当したプロダクト業務と具体的なプロジェクトを説明してください。 |
| 上海も検討 | 豆包AIプロダクト。プロトタイプ、AIアプリ、評価の実務が関係します。実際のプロジェクトで設計と協力の進め方を示し、上海で働けるかを確認してください。 |
| プラットフォーム系は経験の補足が必要 | テンセント混元API（深圳／北京）、レノボのデータエージェント（北京）。APIの利用と評価の経験はありますが、企業向けプラットフォームの担当経験はまだ示せていません。 |

公開用に匿名化した過去の調査の抜粋です。別に載せている架空の履歴書はレイアウトの見本で、その経歴はこの判断に使っていません。

## 2. 重点求人の分析

### 1. Aime 特化型AIプロダクト｜バイトダンス｜北京

関係する経験：ユーザーの課題分析、AIワークフロー、効果評価の経験が仕事内容と重なります。AIプロダクトの経験が1年以上必要なので、今の仕事の関連業務が年数に数えられるかを先に確認してください。

足りない説明：一つのプロダクト場面を、要件、機能設計からリリースまで担当し、その後の利用状況を追い続けたかどうかが、履歴書からは分かりません。

応募前の準備：実際に作ったワークフローを一つ選び、要件の説明、フロー図またはプロトタイプ、受け入れの方法、改善の記録を用意します。自分が何を決めたかを書いてください。

### 2. 社内情報システムのAI評価｜バイトダンス｜北京

関係する経験：一括評価のスクリプトを作り、品質基準も定めています。この求人は評価を社内で使うプロダクトにする仕事で、今の経験に近いです。

足りない説明：評価ができることは分かりますが、アルゴリズム、開発、データの各チームとどう協力して、使い続けられる基盤にしたかはまだ説明されていません。

応募前の準備：評価サンプル、採点ルール、誤りの分類、バージョン比較を見せ、評価結果から次に何を直すと決めたかを説明します。

### 3. オフィス向けAIの効果評価｜バイトダンス｜北京

関係する経験：ワークフロー設計と品質評価の経験は、タスクの分解と問題の発見を説明する材料になります。理工系の学位は条件を満たします。関連経験3年以上は歓迎条件で、必須ではありません。

足りない説明：職種ごとのタスク設計、エージェントの実行過程の分析、改善効果の検証について、具体例がまだありません。

応募前の準備：実際のオフィス業務を一つ選び、入力、使ったツール、採点方法、失敗の原因を示し、修正後に良くなったと判断した根拠を説明します。

### 4. 豆包AIプロダクト｜バイトダンス｜上海

関係する経験：プロトタイプ、AIアプリ、評価の実務を重視する求人で、あなたの個人プロダクトと評価の経験に近いです。募集ページに経験年数の条件はありません。

足りない説明：要件定義書、インタラクションのプロトタイプ、開発やデザインと協力してリリースした経験を示す必要があります。勤務地は上海なので、先に受け入れられるかを確認してください。

応募前の準備：実際のプロダクトを一つ使って、ユーザーの要望、設計上の判断、評価方法を説明します。関係する経験を履歴書の前のほうに置き、自分が担当した範囲はそのまま書きます。

### 5. 混元APIプロダクト企画｜テンセント｜深圳／北京

関係する経験：PythonスクリプトとAPIを使った経験があり、モデルのインターフェースの機能、パラメータ、効果の検証から話せます。この求人は企業向けプラットフォームの経験も求めています。

足りない説明：APIのリリース、変更、互換性の管理についての経験が書かれていません。実際に関わったプロジェクトと自分の担当を補ってください。

応募前の準備：APIのテスト記録を用意し、パラメータ、応答時間、エラー処理、出力の質、コストを比べます。面談では職位とチームの分担を聞いてください。

### 6. AIデータエージェントプロダクト｜レノボ｜北京

関係する経験：業務上の課題を理解し、AIデータエージェントの機能にする仕事です。ユーザーの課題分析、要件整理、効果評価の経験から話を始められます。

足りない説明：データ基盤の管理、プロダクトの収益化、要件からリリースまでを一人で進めた経験があるかどうかが、履歴書からは分かりません。

応募前の準備：データ照会またはレポート作成アシスタントの案を1ページにまとめ、利用者、権限、失敗時の対応、受け入れの方法を書きます。新しく作った案は準備用の作品だと明記します。
