# AI 프로덕트 매니저 구직 보고서

조사일: 2026년 9월 11일 | 중국 본토, 베이징 우선 | 희망 조건: 세전 고정 월급 30,000위안 초과

## 1. 어디서 시작할까

먼저 베이징의 AI 평가와 AI 애플리케이션 공고를 살펴보기를 권합니다. 사용자 문제 분석, AI 워크플로, 일괄 평가, 개인 제품 개발 경험이 이 공고들의 업무와 겹칩니다. 지금 이력서에는 직접 맡은 기능, 개발자와 협업한 방식, 출시 후 실제 사용 상황이 아직 드러나지 않습니다.

어느 공고도 고정 월급을 공개하지 않았습니다. 준비에 시간을 쓰기 전에 희망 급여에 맞는지 먼저 확인하세요.

이번 목록은 공식 채용 페이지의 60건, 48개 그룹입니다. 이 가운데 16개 그룹은 공고 전문이 있고, 32개 그룹은 목록 요약만 있습니다.

| 연락 순서 | 공고와 확인할 점 |
|---|---|
| 베이징 공고 먼저 | Aime 특화 앱, 사내 정보 시스템 AI 평가, 오피스 AI 효과 평가. 워크플로와 평가 경험이 관련됩니다. 맡았던 제품 업무와 구체적인 프로젝트를 설명하세요. |
| 상하이도 함께 검토 | 더우바오 AI 제품. 프로토타입, AI 앱, 평가 실무가 관련됩니다. 실제 프로젝트로 설계와 협업 과정을 보여 주고, 상하이 근무가 가능한지 확인하세요. |
| 플랫폼 공고는 경험 보완 필요 | 텐센트 훈위안 API(선전 / 베이징), 레노버 데이터 에이전트(베이징). API 사용과 평가 경험은 있지만, 기업용 플랫폼을 맡은 경험은 아직 드러나지 않습니다. |

공개용으로 익명화한 과거 조사의 발췌입니다. 따로 실린 가상 이력서는 서식 예시이며, 그 경력은 이 판단에 쓰지 않았습니다.

## 2. 주요 공고 분석

### 1. Aime 특화 AI 제품 | 바이트댄스 | 베이징

관련 경험: 사용자 문제 분석, AI 워크플로, 효과 평가 경험이 이 공고의 업무와 겹칩니다. AI 제품 경력 1년 이상을 요구하므로, 지금 하는 일의 관련 업무가 경력으로 인정되는지 먼저 확인하세요.

부족한 설명: 한 가지 제품 상황을 요구사항과 기능 설계부터 출시까지 맡고, 이후 사용 현황을 계속 살폈는지가 이력서에 나와 있지 않습니다.

지원 전 준비: 직접 만든 워크플로 하나를 골라 요구사항 설명, 흐름도나 프로토타입, 검수 방법, 개선 기록을 준비하고, 본인이 무엇을 결정했는지 적으세요.

### 2. 사내 정보 시스템 AI 평가 | 바이트댄스 | 베이징

관련 경험: 일괄 평가 스크립트를 만들었고 품질 기준도 정했습니다. 이 공고는 평가를 사내에서 쓰는 제품으로 만드는 일이라 지금 경험과 가깝습니다.

부족한 설명: 평가를 할 수 있다는 점은 보이지만, 알고리즘, 개발, 데이터 팀과 어떻게 협업해 계속 쓸 수 있는 플랫폼으로 만들었는지는 아직 설명되지 않았습니다.

지원 전 준비: 평가 샘플, 채점 규칙, 오류 분류, 버전 비교를 보여 주고, 평가 결과로 다음에 무엇을 고칠지 어떻게 정했는지 설명하세요.

### 3. 오피스 AI 효과 평가 | 바이트댄스 | 베이징

관련 경험: 워크플로 설계와 품질 평가 경험으로 과제를 나누고 문제를 찾는 방법을 설명할 수 있습니다. 이공계 학위는 요건에 맞습니다. 관련 경력 3년 이상은 우대 사항이고 필수는 아닙니다.

부족한 설명: 직무별 과제 설계, 에이전트 실행 과정 분석, 개선 효과 검증에 대한 구체적인 사례가 아직 없습니다.

지원 전 준비: 실제 사무 업무 하나를 골라 입력, 사용한 도구, 채점 방법, 실패 원인을 보여 주고, 고친 뒤 실제로 나아졌다고 판단한 근거를 설명하세요.

### 4. 더우바오 AI 제품 | 바이트댄스 | 상하이

관련 경험: 프로토타입, AI 앱, 평가 실무를 중시하는 공고로, 개인 제품과 평가 경험에 가깝습니다. 채용 페이지에 경력 연수 요건은 없습니다.

부족한 설명: 요구사항 문서, 인터랙션 프로토타입, 개발과 디자인 담당자와 협업해 출시한 경험을 보여 줘야 합니다. 근무지가 상하이이므로 가능한지 먼저 확인하세요.

지원 전 준비: 실제 제품 하나로 사용자 요구, 설계에서 내린 선택, 평가 방법을 설명하세요. 관련 경험을 이력서 앞쪽에 두고, 본인이 맡은 범위는 그대로 적으세요.

### 5. 훈위안 API 제품 기획 | 텐센트 | 선전 / 베이징

관련 경험: Python 스크립트와 API를 써 본 경험이 있어, 모델 인터페이스의 기능, 매개변수, 효과 검증부터 이야기할 수 있습니다. 이 공고는 기업용 플랫폼 제품 경험도 요구합니다.

부족한 설명: API 출시, 변경, 호환성 관리 경험이 이력서에 없습니다. 실제로 참여한 프로젝트와 본인 역할을 보완하세요.

지원 전 준비: API 테스트 기록을 준비해 매개변수, 응답 시간, 오류 처리, 출력 품질, 비용을 비교하세요. 면담에서는 직급과 팀 내 역할 분담을 물어보세요.

### 6. AI 데이터 에이전트 제품 | 레노버 | 베이징

관련 경험: 업무 문제를 이해해 AI 데이터 에이전트 기능으로 만드는 일입니다. 사용자 문제 분석, 요구사항 정리, 효과 평가 경험에서 이야기를 시작할 수 있습니다.

부족한 설명: 데이터 플랫폼을 관리했는지, 제품 수익화를 맡았는지, 요구사항부터 출시까지 혼자 이끌었는지가 이력서에 나와 있지 않습니다.

지원 전 준비: 데이터 조회 또는 보고서 도우미 기획안을 한 장으로 정리해 사용자, 권한, 실패 시 대응, 검수 방법을 적으세요. 새로 만든 기획안은 준비용 작업물이라고 표시하세요.
